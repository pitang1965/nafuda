# "仕事じゃない出会い"のための名刺をつくった話

自己紹介ページとデジタル名刺交換をひとつにしたサービス「なふだ」( https://nafuda.me )をつくっています。何を考えて始めたのか、どんな機能があるのかを書いてみます。

## きっかけは「紹介ページ」と「名刺交換」を1つにしたかったこと

linktreeや リトリン(lit.link)のような、自分のことを1ページにまとめて紹介できるミニホームページ。SNSも作品も活動も、リンクを1つ渡すだけで見てもらえる。あの手軽さが好きでした。

ただ使ううちに、「これがそのまま**その場での名刺交換**にも使えたら」と思うようになりました。

- 紹介ページとしては便利だけど、**目の前の相手とその場でつながる**動きにはなっていない
- 紙の名刺は、渡したあと結局どこかにいってしまう
- かといって、初対面でSNSを全部その場で教えるのも少し構える

「自己紹介ページ」と「その場のデジタル名刺交換」。この2つがひとつになったものが欲しい ── それが「なふだ」の出発点です。

## 「見せる」と「交換する」を分けました

なふだには、渡し方が2つあります。

- **なふだを見せる** … 自分のプロフィールをQRで見せるだけ。永続的なURLなので、印刷してもSNSに貼ってもいい。あくまで**閲覧**で、つながりは発生しません。
- **なふだを交換する** … その場だけの短命QR(15分有効)を出し、相手がスキャンして「つながる」を押すと、**双方向のつながり(コネクション)がその場で成立**します。これが紙の名刺交換に相当します。

「今はプロフィールを見てほしいだけ」と「ちゃんとつながりたい」を、はっきり分けたかったんです。

## こんな場面で使えたら、と思っていました

### バーで知り合った、地元のおじちゃん・おばちゃんに

これは実際に「あったらいいな」と強く思った場面です。ふらっと入ったバーで話が弾み、紙の名刺をもらう。うれしいけれど、こちらは名刺を持っていない。そんなとき、**紙の名刺の代わりにさっと渡せる**ものがあったら。

かしこまったビジネスの場ではなく、こういう**ゆるい出会いの場**でこそ、デジタルの名札は役に立つ。だから「なふだ」は、**"仕事じゃない"出会いでSNSにつながる**ことに軸を置いています。仕事の名刺は Eight のような世界に任せて、勉強会・趣味のオフ会・懇親会・バーでの出会いを守備範囲にしています。

### 同じものを"推している"人同士がつながる

イベント会場で隣に居合わせた人と「同じ人を推してるんだ!」と意気投合する。連絡先をイチから交換するのは重いけれど、なふだなら見せて交換するだけ。あとからゆっくりお互いのプロフィールを見返せます。

正直に言うと、**私自身は推し活はしていません**。それでも、同じ対象を好きな人同士がその場でつながる場面は、なふだが一番輝くユースケースだと思っています(なので**推しタグ**や、推し活以外でも使える**興味タグ**を用意しました)。

## 「いつ・どこで会ったか」が自動で残る

名刺交換のもったいないところは、時間が経つと「この人、どこで会ったんだっけ?」となること。

なふだでは、**イベントにチェックインした状態で交換すると、「いつ・どこで会ったか」がつながりの記録に自動で付きます**。事前に作る**企画イベント**(ライブ・オフ会・勉強会など、公開ページを持てる)でも、交換のその場でつくる**即時イベント**(「バーナイト＠立川」のような、その場かぎりの記録)でもOK。あとから自分用のメモを書き足すこともできます。

## 出会いを、夜空として眺める

つながりが増えてきたら、**出会いの夜空**で振り返れます。ひとつの出会いが、ひとつの星。同じイベントで出会った人たちは線で結ばれて、星座になります。

ここには「関係の強さ」や「やりとりの多さ」といった評価は一切持ち込みませんでした。**どの出会いも、等しくひとつの星**。実務的なつながり一覧とは別に、ただ静かに眺めて振り返るための場所です(名前や地名を含まないPNGとして書き出すこともできます)。

## その他の機能

- **SNSリンク** … X / Instagram / TikTok / YouTube / Discord / LINEオープンチャット / GitHub / Spotify / Suno / Facebook / みんカラ / LinkedIn / note / pixiv などに対応。
- **ギャラリー** … 写真を最大6枚まで。「Linktreeは写真を出せないのが残念」という声から生まれた機能で、推し・作品・愛車などを画で見せられます。
- **お気に入り** … 気になった相手のなふだを手元に保存。**相手には通知されず、誰に保存されたかも分からない**、静かなブックマークです。
- **なふだスタイル** … 背景・フォント・縁取りを組み合わせた見た目のパッケージ。傾けると虹色に光るスタイルもあります。
- **用途別に複数持てる** … 「趣味用」「婚活用」「車用」など、1人で複数のなふだを使い分けられます。相手に見せる名前とは別に、自分だけが見える識別名(ラベル)も付けられます。
- **なふだマップ** … 増えてきた自分のなふだ同士のつながりを1画面で俯瞰し、「このなふだを見せると、どこまで見えてしまうか」を自分で確認できます。

## これから

なふだは、「自分を紹介したい」と「その場でつながりたい」のあいだを、ちょうどよく埋めたくてつくっています。

推しが同じ人にも、趣味の仲間にも、バーで出会った地元の先輩たちにも。紙の名刺の代わりに、気軽に渡せる一枚を目指しています。
