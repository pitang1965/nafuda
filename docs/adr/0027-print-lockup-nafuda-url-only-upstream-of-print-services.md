# ADR-0027: 印刷用ロックアップはなふだURL専用の入稿画像として書き出し、グッズの合成・印刷・販売は外部サービスに委ねる

- **ステータス**: 採用
- **決定日**: 2026-08-10
- **関連**: ADR-0013（つながりQRに配布導線を持たせない）／装飾QR（decorated QR）実装の延長

## 背景

なふだの宣伝手段として「なふだのQRコードを大きく配して文言（例: "Scan me!"）を添えたTシャツ」を作りたい、という発想が出発点。SUZURI 等のオンデマンド作成サービスにデザインを上げれば、1枚から自作・販売できる。

既存資産として、プロフィールQR／イベントQRを画面から保存する `saveQrImage`（[QRBottomSheet.tsx](../../src/components/QRBottomSheet.tsx)）がある。これは 1024px・`level="M"`・ラベル＋QR＋「nafuda.me」帯を**白背景ベタ**で合成する**画面用途**の書き出しで、そのままではグッズ印刷に向かない（低解像度・色付きTシャツで白い長方形が乗る・洗濯で毀損しやすい訂正水準）。

ここで問われたのは、なふだが「印刷・グッズ作成」にどこまで踏み込むか。市場調査では、SUZURI は「Tシャツ 自作」でも「オリジナルTシャツ 作成」でも Google 検索3ページ目に沈む——**印刷・販売レイヤーは競合が飽和**している。ここに素手で参入するのは筋が悪い。

## 決定

**プロフィールQRをグッズ印刷向けに書き出す「印刷用ロックアップ」を新設し、なふだは入稿画像（素材）の生成に徹する。グッズへの配置・印刷・販売は外部サービス（SUZURI 等）に委ねる。**

成果物の仕様（詳細は CONTEXT.md「[[印刷用ロックアップ]]」を参照）:

- **構成要素**: QR＋文言＋「nafuda.me」＋なふだマーク（NafudaIcon）の固定組版。[[ラベル]]（オーナー専用の自己識別名）は焼き込まない（公開物に出さない原則）。アバター（顔写真）も入れない（物理媒体への恒久的なプライバシー露出を避ける）。
- **文言**: プリセット選択＋自由入力。"Scan me!" も一案として残すが、なふだ流の言い回し（「なふだ、見てって」等）を主役に据える。行き先は**常に自分のなふだURL**に限る。
- **埋め込むQR**: 永続の[[プロフィールQR]]のみ。短命の[[つながりQR]]は対象外（グッズに載せても無意味、ADR-0013 の配布導線非付与とも一致）。
- **入稿仕様**: 透過PNG／RGB、長辺 ~4000px 級（SUZURI 4192×4724・UP-T 3600×4890・200〜300dpi をカバー）。QR誤り訂正は `level="H"`（洗濯・シワ・伸縮での毀損に備える）。**白い角丸カードに全要素を載せ、カードの外側は透過**（色付きグッズでも意図した白バッジとして成立し、QRのクワイエットゾーンとコントラストを確保）。
- **置き場所・公開範囲**: [[なふだを見せる]]の流れから開く軽い合成画面（文言選択＋プレビュー＋書き出し）。全ユーザーが使える控えめな二次アクションとして提供する。開発者自身が最初のユーザーとして使い、需要シグナルが出たら導線の露出度を上げて「昇格」させる（アクセス制限ではなく prominence の問題）。

**境界（やらないこと）**:

- **汎用QRツールにしない** — 任意URLは対象外。なふだURL専用に絞ることが差別化そのもの。
- **合成はロックアップまで** — Tシャツ本体への配置・モックアップは作らない（SUZURI エディタの役割）。イメージは静的な作例で補う。
- **印刷・販売・POD連携をしない** — 外部サービスに委ねる。
- **CMYK・プロ入稿（AI/PSD）に対応しない** — 消費者向けフローは RGB PNG 入稿。

## 却下した代替案

- **Tシャツ完成デザイン／モックアップまで生成する**: 完成イメージは楽しいが、「Scan me!」を仕様として焼き込むと、既存Tシャツと同じ文言を製品仕様として抱え込み**パクリ懸念を構造化**する。SUZURI エディタの配置自由も奪う。作例（静的例示）でイメージは十分湧く。
- **任意URL対応の汎用QR素材ツール**: 差別化（moat）を捨て、SUZURI が3ページ目に沈む**飽和市場に素手で参入**することになる。なふだ専用に絞るからこそ、スキャン先に本人のつながり導線がある実用性が生きる。
- **バラのQR素材だけを書き出す**: 文言合成の楽しさと販促力を捨てる。合成UIは軽く（文言プリセット＋プレビュー）割に合う。
- **別プロダクトとして切り離す**: 認証・なふだデータ参照・保守がまるごと二重になる。実体は装飾QR（decorated QR）書き出しの印刷向け拡張で足り、新規プロダクトを名乗る重さはない。
- **隠し機能（フラグ/env でゲート）**: プロフィールQRは既に公開・配布可能な資産で、隠す実利がない。ゲート基盤の実装が過剰。
- **CMYK／プロ入稿対応**: 対象が消費者向けフロー（RGB PNG 入稿）で、本デザインはほぼモノクロ（黒QR＋白カード＋ピンク文字＋小アイコン）ゆえ色ズレが実害にならない。過剰投資。

## トレードオフ

- **失うもの**: 「そのまま着られる完成品」の一気通貫体験。グッズ化の最後の一歩（配置・発注）はユーザーが外部サービスで行う手間。印刷・販売レイヤーの収益機会。
- **得るもの**: 飽和した印刷・販売市場と戦わず**上流に徹する**立ち位置（SUZURI の競合ではなく素材供給元）。なふだ専用ゆえの差別化。既存書き出しの延長で済む最小実装。文言を選択制にすることでパクリ懸念を構造的に回避。
- **許容できる理由**: 元々の目的は「なふだの宣伝」であり、質の高い入稿画像が出せれば達成できる。印刷・物流・決済を背負う投資は目的に不釣り合い。需要が見えてから導線を昇格させる余地も残せる。
